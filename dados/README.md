# Dados

Os arquivos originais não estão neste repositório por causa do tamanho.

## Como obter

1. Acesse o [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) no Kaggle.
2. Clique em **Download** (é necessário ter uma conta gratuita).
3. Extraia o arquivo `.zip`.

## Arquivos usados neste projeto

- `olist_orders_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_order_reviews_dataset.csv`

Os demais arquivos da base (produtos, vendedores, pagamentos, geolocalização) não foram utilizados.
